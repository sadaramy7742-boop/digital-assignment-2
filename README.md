# Digital Assignment

Project name: Digital Litecracy Assignment 2.

Build a polished, human-designed single-page e-commerce website with an inventory management panel for a first-year B.Tech CSE digital literacy assignment. Use the visible store brand "TechStore" but name the Lovable project "Digital Litecracy Assignment 2". Make the site modern, responsive, clear, and genuinely interactive, not a static mockup.

Requirements:
- Single-page electronics store with navigation, search, category filters, product grid, product cards, cart drawer/panel, quantity controls, and simulated checkout.
- Inventory management/admin panel accessible from a clear button/tab, with add product, edit product, delete product, change stock, and low-stock warnings below 5 units.
- Dashboard metrics: number of products, total units, low-stock items, and order count. All metrics should be calculated from the app's product/order state, not hard-coded.
- Use demonstration product data and make it clear it is sample/demo data. No real payment processing, no fabricated claim of real sales, no unnecessary sign-in. Make product/inventory/cart interactions work. Persist state with localStorage if appropriate.
- Provide useful empty states, form validation, confirmations for destructive actions, and responsive accessible UI.
- Include product images or polished image placeholders; use a premium midnight-navy / off-white palette with subtle blue accents, clean typography, thoughtful spacing, no excessive gradients.
- Add a small "About this project" section explaining that this is a student demonstration of e-commerce and inventory management.
- Ensure the app runs and builds without errors.
- Do not invent deployment URLs or claim GitHub/Vercel integration has happened automatically. After implementation, summarize the features and any manual steps still needed.
